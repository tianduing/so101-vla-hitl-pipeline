## 新问题记录规范

建议编号格式：

```text
领域-问题类型-序号_简短名称.md
```

每篇至少包含：

1. 用户看到的现象；
2. 容易误判的解释；
3. 实际证据；
4. 根因；
5. 修复过程；
6. 无效尝试；
7. 验证结果；
8. 下次定位清单；
9. 可复现命令和输出路径。
