## 一、环境

```bash
git clone https://github.com/tianduing/so101-vla-hitl-pipeline.git
cd so101-vla-hitl-pipeline
source env.sh
export MUJOCO_GL=egl
export PYOPENGL_PLATFORM=egl
export PYTHONPATH="$PWD/sim_mujoco/src:$PWD/src"
```
