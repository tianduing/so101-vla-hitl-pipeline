# SO-101 抓取：从近似 0% 到完整系统 85% 的学习手册

更新时间：2026-08-13

## 先说最终结论

现在可以说：**在 MuJoCo 仿真、项目原成功标准、20个未参与调参的新位置上，完整视觉抓取系统取得了17/20，也就是85%。**

但是不能说：**ACT或VLA模型本身已经达到85%。**

当前几个容易混淆的数字如下：

| 对象 | 测试集 | 成绩 | 能说明什么 |
|---|---|---:|---|
| ACT三专家 | 已知开发位置 seed 42–51 | 9/10，90% | 对已知位置修复有效，不能代表泛化 |
| 单ACT主模型 | 未见位置 seed 52–71 | 9/20，45% | 当前最可信的单模型泛化能力 |
| 多个ACT专家事后成功并集 | 未见位置 seed 52–71 | 14/20，70% | 假设事先知道该选谁的理论上限分析 |
| RGB视觉检索恢复系统 | 未见位置 seed 52–71 | 17/20，85% | 完整工程系统达到目标 |
| 抓起后再稳定保持3秒 | 已知位置 seed 42–51 | 4/10，40% | 长时间稳定夹持仍是明显短板 |

一句通俗比喻：

- ACT模型像一名只凭经验抓东西的学徒；
- RGB恢复器像一本“看到物块在哪，就查找最相近成功案例”的操作手册；
- 85%是“学徒加操作手册”的系统成绩，不是学徒单独考试的成绩。

## 为什么最开始看起来接近0%

早期最严重的问题不是模型一定没学会，而是推理程序可能没有真正加载训练后的权重：

- ACT可能实际使用随机初始化权重；
- SmolVLA可能加载基础模型，而不是100k训练检查点；
- 输出文件名却仍带着目标检查点名称，让人误以为模型训练无效。

这类似于学生已经做完练习，但考试时发给他的却是空白草稿或旧课本。此时成绩接近0，不能据此判断训练方法失败。

修复权重加载后，单ACT达到5/10，SmolVLA最佳配置达到4/10。后续才进入真正的数据覆盖、闭环误差和接触稳定性优化。

## 最重要的五条经验

1. 先验证内存中的权重确实来自目标checkpoint，再讨论训练好坏。
2. 离线动作误差不是闭环抓取成功率，风险分类准确率更不是抓取成功率。
3. 开发集90%不能冒充未见位置90%；必须保留完全未参与调参的盲测位置。
4. 简单把动作放慢不会天然提高准确率，本项目实测反而从70%降至40%–60%。
5. 85%只完成了“小样本仿真工程目标”，还没有证明真机、长时间保持和单模型泛化达到85%。
