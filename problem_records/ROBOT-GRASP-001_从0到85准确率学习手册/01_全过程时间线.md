# 01 从近似0%到85%的全过程时间线

## 阶段0：工程冒烟测试被误解成“已经训练好”

最初的三个新checkpoint只训练了1 step。它们只能证明：

- 训练程序能启动；
- 权重能保存；
- checkpoint能离线加载；
- 推理API能返回动作。

它们不能证明模型已经学会抓取，也不能统计抓取成功率。

同时出现过85.7%的数字，那是风险分类器的帧级验证准确率。它回答的是“这张画面是否属于某类风险”，不是“机器人能否把方块抓起来”。

## 阶段1：动画抓不起来，表面上接近0%

早期策略闭环视频中，ACT和SmolVLA经常完全抓不到。这时有三个可能：

1. 模型没训练好；
2. 数据与仿真不匹配；
3. 推理程序根本没有使用目标权重。

实际首先查出了第3类严重错误：

- ACT可能按配置重新实例化随机权重；
- SmolVLA读取了训练初始化时的`pretrained_path`，加载基础模型；
- 视频文件名仍使用用户传入路径的哈希，造成“看起来加载正确”的假象。

### 修复

推理适配器现在强制从调用者指定的checkpoint加载，并抽取真实张量逐元素比较：

```text
磁盘checkpoint张量 == 内存模型同名张量
```

形状或任意数值不同就立即报错，不再生成来源不明的视频。

## 阶段2：权重修复后，得到真正的模型基线

权重加载修复后：

- 单ACT：5/10，50%；
- SmolVLA 10步动作队列：3/10，30%；
- SmolVLA 20或50步：4/10，40%。

这一步非常关键，因为从这里开始，失败才主要属于模型、数据和闭环控制问题，而不再是“拿错模型”。

## 阶段3：构建真正物理有效的仿真数据

旧式关节回放可能出现一种假数据：机器人按示范运动，但方块没有真实跟随夹爪运动。这种数据图像、状态和动作不具有因果一致性。

后来构建的数据必须满足：

1. 夹爪与方块发生MuJoCo接触；
2. 存在摩擦和重力；
3. 方块实际抬升至少20 mm；
4. 抬升持续至少0.25秒；
5. 只有通过物理验证的轨迹才能写入数据集。

基础物理数据集包含160个episode、23,169帧。

## 阶段4：发现两个ACT各有擅长区域

主ACT和辅助ACT单独都大约只有5/10，但成功位置并不完全相同。

尝试过直接平均模型权重或交换归一化统计，结果为0/10或接近0/10。原因是模型参数和归一化尺度必须配套，简单平均相当于混用两把刻度不同的尺子。

后来改为根据初始相机RGB中绿色物块的横向像素中心选择专家：

```text
绿色中心 x >= 195：主专家
绿色中心 x < 195：辅助专家
```

两次完整测试分别8/10和6/10，合计14/20，即70%。

## 阶段5：专门修复稳定失败的seed 48、49

这两个位置原数据最近成功轨迹仍相距约8 mm。抓取任务里8 mm可能足以从“夹住中心”变成“擦到边缘”。

处理方法：

1. 穷举回放160条源轨迹；
2. 找出在seed 48、49附近能够物理成功的源动作；
3. 在难例中心周围±3 mm建立网格；
4. 只写入严格物理成功的100条、15,165帧轨迹；
5. 从最佳ACT继续微调；
6. 每100 step保存一次，避免训练过头。

100 step专家对seed 48、49达到2/2。加入第三专家后，已知开发位置seed 42–51达到9/10，即90%。

## 阶段6：用未见位置戳破“模型90%”的错觉

使用完全未参与训练与路由选择的seed 52–71测试：

- 单ACT主模型：9/20，45%；
- 辅ACT：5/20，25%；
- 多专家事后成功并集：14/20，70%。

这说明90%只代表已知开发位置修复成功，不代表普遍泛化。

## 阶段7：补充广覆盖数据，训练新的ACT专家

围绕左侧低覆盖区域生成：

- 主左侧多轨迹数据：131条、20,629帧；
- 左侧高Y数据：53条、8,543帧；
- 左侧低Y数据：52条、7,902帧；
- 单轨迹全网格数据：30条、4,830帧。

实验发现：

- 只重复单一轨迹的专家不能解决泛化；
- 多轨迹专家在未见位置上约10/20，50%；
- 数据更多不等于自动更好，轨迹多样性和动作—物块位置的一致性更重要。

## 阶段8：完整工程系统达到17/20

由于纯模型的未见位置专家并集仍不足85%，新增了透明的RGB视觉检索恢复器：

1. 离线用42个位置标定绿色像素中心到桌面XY；
2. 标定平均绝对误差约0.139 mm；
3. 运行时只读取初始RGB画面；
4. 从全部物理成功示范中找预测XY最近的轨迹；
5. 执行该轨迹完成恢复抓取。

在seed 52–71上成功17次，失败3次，达到85%。

## 阶段9：慢动作和稳定保持测试

整体慢两倍并没有更准：

| 配置 | 结果 |
|---|---:|
| 动作重复2次 | 6/10 |
| EMA平滑、每步限制3° | 4/10 |
| 慢2倍加平滑 | 5/10 |

抓起后冻结机械臂并保持3秒的严格测试只有4/10，说明部分成功属于边缘夹持：能够越过20 mm门槛，但长期会滑落。

因此当前最准确的总结是：

> 项目已经把“仿真中完成一次抓取”的完整系统提高到85%，但模型泛化和稳定夹持还没有达到85%。
