# 09 抓取实验记录模板

每次新实验复制下面内容，填写后与结果JSON一起保存。

## 实验身份

- 实验名称：
- 日期时间：
- 执行人：
- Git commit或本地代码状态：
- 是否有未提交改动：

## 研究问题

- 想验证什么：
- 唯一主要改动：
- 预期结果：
- 明确不改变的变量：

## 模型

- 模型类型：ACT / SmolVLA / Diffusion / 恢复器
- checkpoint绝对路径：
- checkpoint SHA256：
- 权重探针张量：
- 内存权重验证：true / false
- 动作块长度：
- 实际执行步数：

## 数据

- 数据集路径：
- episode数：
- 帧数：
- 物块XY范围：
- 是否逐轨迹物理验证：
- 是否包含测试位置：

## 环境

- 仿真/真机：
- 控制频率：
- 物理频率：
- 方块尺寸与质量：
- 摩擦参数：
- 相机与光照：
- GPU与显存：

## 评测协议

- seed列表：
- 开发集/验证集/盲测集：
- 最大时长：
- 抬升门槛：
- 最短保持时间：
- 是否额外测试3秒稳定保持：
- 是否允许恢复：
- 在线是否使用仿真特权状态：

## 结果

- 成功次数/总次数：
- 成功率：
- 95%置信区间：
- 失败seed：
- 完全未接触次数：
- 接触但未抬起次数：
- 抬起后滑落次数：
- 平均/最大接触力：
- 视频目录：
- summary.json路径：

## 结论

- 结果是否支持假设：
- 与基线相比提高或下降多少：
- 是否存在评测泄漏：
- 是否值得继续训练：
- 下一实验只改什么：

## 禁止省略的检查

- [ ] checkpoint权重实际验证通过
- [ ] 每次试验有逐样本JSON
- [ ] 成功门槛没有临时降低
- [ ] 失败视频仍被保留
- [ ] 开发集和盲测集没有混用
- [ ] 系统成绩没有错误归因给单模型
- [ ] 在线策略没有偷偷读取物块真值
