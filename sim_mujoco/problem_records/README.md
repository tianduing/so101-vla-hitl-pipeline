## 状态定义

- `待定位`：现象已复现，但根因尚未确认；
- `已定位`：根因有日志或实验支持，尚未完成修复；
- `已修复`：修复已运行，并有前后量化对比；
- `受限`：由于缺资产、权限或硬件，暂时不能继续验证；
- `误报`：确认不是系统缺陷，仍保留判断证据。

## 分类建议

- `SIM-CTRL`：控制器、IK、轨迹、振荡；
- `SIM-PHYS`：碰撞、摩擦、质量、数值稳定性；
- `SIM-MAP`：真机数据与 MuJoCo 关节/动作映射；
- `SIM-RENDER`：EGL、相机、编码、黑屏；
- `POLICY`：Checkpoint、schema、推理、Real-to-Sim；
- `TRAIN`：训练、FSDP、显存和 checkpoint；
- `DATA`：数据集、时间戳、视频和标签。

## 新问题登记流程

1. 复制 [`TEMPLATE.md`](TEMPLATE.md)，命名为 `分类-ID_简短标题.md`；
2. 保存原始日志、视频或 JSON 路径，禁止只凭观感下结论；
3. 区分模型问题、控制器问题、物理问题和视频编码问题；
4. 保留失败版本，不用修复后的产物覆盖全部证据；
5. 至少给出一个修复前后可比较的量化指标；
6. 在本索引表增加一行。

这里不存放大型视频副本，文档引用 `outputs/` 下的只增不改证据，避免重复占用磁盘。
