# 从 62% 提升成功率的路线

## 根因优先级

1. **空间覆盖缺口**：`unseen_low_y` 和 `unseen_left_extreme` 均为 0/5；黄色干扰训练集中对应极端位置只有 2 条和 4 条。
2. **闭环误差累积**：行为克隆在训练分布外偏一步后，会进入更陌生的观测状态；仅增加相同分布 epoch 通常无法解决。
3. **视觉信息不足**：公开训练集只有一个 scene 相机，而私有技术方案是双相机；遮挡、夹爪深度和末端接近阶段缺少视角冗余。
4. **评测量仍小**：50 次只能定位明显失败桶，不能给细粒度策略差异提供稳定估计。

## 第一轮：先补最值钱的数据

建议新采 150–220 条人工验收通过的 episode：

| 数据桶 | 建议数量 | 目的 |
|---|---:|---|
| low-y（尤其 `< 22 mm`） | 40–60 | 修复当前 0/5 失败桶 |
| left-extreme（尤其 `< -25 mm`） | 40–60 | 修复当前 0/5 失败桶 |
| left-low 交叉区域 | 20–30 | 覆盖两个因素共同出现 |
| 黄块近距离/遮挡 | 30–40 | 防止抓错干扰物 |
| 失败恢复与 HITL 纠偏 | 20–30 | 学习偏离后的恢复轨迹 |

采集时按固定 placement 清单做分层采样，不采用纯随机。保存目标/干扰物坐标、相机标定、是否成功、失败类型和接管点。每条先做视频、时序、关节范围和任务文本审计，不合格样本不进入训练。

## 第二轮：重放与训练配比

初始建议的 batch 采样比例：

- 50% 原始多样性数据；
- 25% low-y / left-extreme hard cases；
- 15% 黄块近距离和遮挡；
- 10% HITL 失败恢复。

不要简单拼接后均匀采样，否则少量 hard cases 会再次被 160 条基线稀释。建议三阶段：

1. 基线全量训练约 30k steps；
2. hard-case 平衡重放约 10k steps；
3. HITL 纠偏低学习率微调 3k–5k steps。

ACT、Diffusion、SmolVLA 使用同一数据划分和 placement 评测集；每轮只改变一个主要因素，保留 checkpoint 和报告。

## 第三轮：双相机和闭环 HITL

- 增加固定 scene/front 与 wrist 两路同步相机，统一曝光、白平衡、分辨率和时间戳。
- 每次变动相机后重新标定并保存版本号；训练与部署使用相同 crop/resize/rename map。
- Round 1 收集风险触发和人工接管片段，创建不可覆盖的 replay v1；重新训练后在固定 50 placements 上评测。
- Round 2 专采 Round 1 剩余失败桶，创建 replay v2，再做盲测。
- 风险模型阈值在独立验证集上按“漏报成本 > 误报成本”标定，同时报告接管率和漏报率，不能只报 accuracy。

## 通过标准

建议阶段目标，而非结果承诺：

- 每个关键空间桶至少 20 次盲测；
- 总成功率 ≥ 80%，且 low-y、left-extreme 各 ≥ 70%；
- 无关节越界或未处理的急停事件；
- 在成功率不下降的前提下逐轮降低人工接管率；
- 新模型相对基线的 95% 置信区间和逐桶结果同时归档。

最高优先级不是继续盲目加训练步数，而是补齐两个 0/5 区域的高质量双相机示教和失败恢复数据。
